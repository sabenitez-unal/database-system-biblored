# Base de Datos para la Red de Bibliotecas Públicas de Bogota - BIBLORED

Proyecto académico realizado para la puesta en práctica de los conocimientos adquiridos en bases de datos relacionales
en la asignatura universitaria de Bases de Datos.
Se utilizó la base de datos **PostgreSQL** para su desarrollo.

## Instalación

1. Asegúrate de tener instalado y configurado [PostgreSQL](https://www.postgresql.org/download/).
    - Debes tener un usuario o host configurado, junto con su contraseña de conexión.
2. Clona el repositorio: `git clone https://github.com/sabenitez-unal/database-system-biblored.git`
3. Entra a la carpeta clonada: `cd database-system-biblored`
4. Ejecuta los scripts SQL de la carpeta `scripts` en estricto orden.
5. Ejecuta, si así lo deseas, los queries de llenado de datos de ejemplo que se encuentran en `./data`.

## Uso

Puedes encontrar queries de consultas de ejemplo en `./queries`.
Puedes instalar DBeaver como Sistema Gestor de Bases de Datos para gestionar la misma desde un
entorno gráfico, haciendo uso de tu host y contraseña de la base de datos.
